# Акции (черновик для сайта)

Рабочие тексты для блока акций на всех страницах (R20). Можно заменить в любой момент.

Ограничения из product-discovery: не обещать «диагностику всегда бесплатно» без условия ремонта; не описывать способы оплаты; только Gaggenau; оригинал запчастей.

---

## Акция A (основная для v1)

**Заголовок:** Сезонная диагностика кухни Gaggenau  
**Подзаголовок:** При заказе ремонта — выезд и диагностика по условиям сервиса без доплаты за визит.  
**CTA:** Оставить заявку  
**Мелкий шрифт:** Итоговая стоимость работ — после осмотра, ориентиры «от …». При отказе от ремонта выезд и диагностика оплачиваются отдельно.

---

## Акция B (альтернатива / ротация)

**Заголовок:** Приоритетный выезд в день обращения  
**Подзаголовок:** В рабочие часы 8:00–22:00 по Москве и МО — постараемся согласовать визит максимально быстро после заявки.  
**CTA:** Позвонить / Оставить заявку  
**Мелкий шрифт:** Слоты зависят от загрузки мастеров и района; точное время подтверждает специалист при звонке в течение 15 минут.

---

## Акция C (для владельцев нескольких приборов)

**Заголовок:** Два прибора Gaggenau — один выезд  
**Подзаголовок:** Если нужна диагностика нескольких устройств, согласуем осмотр в рамках одного визита.  
**CTA:** Оставить заявку  
**Мелкий шрифт:** Состав работ и стоимость — после диагностики каждого прибора.

---

## Рекомендация для макета

В шаблоне на всех страницах показывать **одну** акцию (A по умолчанию), B/C — в запасе для замены без смены вёрстки.
